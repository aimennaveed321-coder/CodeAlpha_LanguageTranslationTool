# CodeAlpha Language Translation Tool

## Task
CodeAlpha Artificial Intelligence - Task 1: Language Translation Tool.

## Features
- Source and target language selection
- Translation API request
- Clear translated output
- Swap source/target languages
- Copy translation button
- Responsive web interface
- Basic error handling

## Technology
- Python
- Flask
- HTML, CSS, JavaScript
- Requests
- MyMemory Translation API

## How to run
1. Install Python 3.10+.
2. Open this folder in VS Code.
3. Open the terminal.
4. Run:
   `pip install -r requirements.txt`
5. Run:
   `python app.py`
6. Open `http://127.0.0.1:5000` in your browser.

## API
The application sends the entered text to the MyMemory translation API and displays the translated response. Internet access is required for translation.
